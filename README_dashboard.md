## 🔧 Quick Start

1. **Clone** the repository:
   ```bash
   git clone <repository_url>
   ```
2. **Install** dependencies:
   ```bash
   npm install
   ```
3. **Run** the application:
   ```bash
   npm run build && npm start
   ```
